# v2.15 项目驾驶舱与统一任务入口交互原型

该目录只用于需求演示，不属于正式应用源码，不读取或写入 Supabase。

## 打开方式

直接用浏览器打开 `index.html` 即可。若浏览器限制本地脚本，可在项目根目录运行：

```powershell
& 'C:\Users\18639\.cache\codex-runtimes\codex-primary-runtime\dependencies\python\python.exe' -m http.server 4173 --directory '.\prototypes\v2.14-project-cockpit'
```

然后访问 `http://localhost:4173/`。

## 推荐演示顺序

1. 在项目列表切换“全部 / 有风险 / 待审批”，判断摘要是否能快速定位问题。
2. 点击凤凰商城的开发任务进度、待审批、逾期或测试中数字，观察是否进入独立“任务管理”页面。
3. 检查地址栏是否携带 `project`、`type`、`status`、`timing` 或 `preset` 条件；刷新页面确认筛选仍存在。
4. 复制当前筛选链接重新打开，确认能恢复来源条件；点击“返回项目驾驶舱”或浏览器返回，确认回到原标签和位置。
5. 在项目概览点击任务状态分布中的待处理、测试中、已完成、延期完成和无负责人风险，核对结果数量。
6. 切换当前身份，在任务管理页验证只有项目负责人可日常审批；部门经理和组长只读，admin 代办必须填写原因。
7. 点击 Bug、不通过、阻断或覆盖指标，确认它们进入项目详情的“测试质量”，而不是任务管理页。
8. 在“测试质量”核对 Bug、Reopen、通过率、测试任务、测试轮次和汇总覆盖率。
9. 在“人员与投入”点击人员，确认进入任务管理并自动携带项目与负责人筛选。

## v2.15 边界

项目详情仅保留“概览、测试质量、人员与投入”。原型中的任务表格和审批操作只出现在独立任务管理页面，不在项目详情重复实现。

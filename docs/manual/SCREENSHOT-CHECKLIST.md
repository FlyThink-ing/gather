# Gather 用户手册截图采集清单

本清单对应 [中文用户操作手册](USER-MANUAL.md#19-截图占位与采集清单)。当前版本没有可确认安全的已登录页面会话，因此不附真实截图，也不使用设计稿或生成图片冒充页面。

## 采集前检查

- [ ] 只使用专用 UAT 环境和虚构数据。
- [ ] 页面中没有真实姓名、邮箱、密码、Token、Cookie、JWT、密钥或环境地址。
- [ ] 浏览器地址栏、收藏栏、其他标签页和桌面通知已隐藏。
- [ ] 禅道链接、项目描述、任务评论和通知内容均已脱敏。
- [ ] 截图文件写入 `docs/manual/images/`，文件名使用下表建议名称。

## 采集后检查

- [ ] 逐张以原始分辨率检查敏感信息和边缘区域。
- [ ] 图片中的按钮文案与当前代码一致。
- [ ] 图片只展示手册中确实存在的功能。
- [ ] 在主手册对应章节插入相对链接并填写简洁替代文本。
- [ ] 运行 Markdown 链接检查，确认所有图片路径有效。
